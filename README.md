# Library Management System (Java)

A complete console-based Library Management System developed in Java, focused on clean architecture and object-oriented programming principles.

## Features
- Book registration and listing
- User management
- Book loan and return system
- Exception handling
- Modular and scalable architecture

## Technologies
- Java 17+
- OOP (Encapsulation, Abstraction, Enums)
- Collections API

## Project Structure
- `model` → Domain entities
- `service` → Business rules
- `exception` → Custom exceptions
- `app` → Application entry point

## How to Run
```bash
javac app/Main.java
java app.Main
